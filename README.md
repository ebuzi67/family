# 우리 가족 대시보드

거실 태블릿에 켜 두는 가족 대시보드예요. 주소: https://ebuzi67.github.io/family/

## 무엇이 있나요
- 시계, 날씨, 미세먼지 (Open-Meteo, 무료)
- 4주 달력 (엄마·아빠·아이·가족 색깔), 오늘/내일 일정
- 아이·엄마·아빠 할 일, 공통 할 일, 장보기
- 여행 준비물 체크리스트
- 다가오는 날 D-day (음력 생신도 올해 양력 날짜로 바꿔서 계산)
- 엄마·아빠는 지금 어디?
- 스티커로 동물 키우기: 북극곰 → 곰 → 꿀벌. 아기(0장) → 어린이(10장) → 다 큰(25장) → 40장이면 동물 마을로 이사
- 자동 화면: 평일 학교 시간엔 차분한 어른 화면, 하교 후·주말·공휴일·방학엔 동물 화면

## 기록은 어디에 저장되나요
**태블릿 브라우저 안에만** 저장돼요. 인터넷으로 보내지 않아요. 그래서 이 저장소를 공개해도 가족 정보는 드러나지 않아요.
대신 브라우저 기록을 지우면 사라지니 **설정 → 백업 파일 저장**을 가끔 해 주세요.

## 처음 쓸 때
1. 태블릿 크롬에서 주소를 열고 메뉴 → **홈 화면에 추가(앱 설치)**를 해요.
2. **설정**에서 이름, 아이 생일, 생일·기념일, 학교 시간, 날씨 지역을 넣어요.
3. 비밀번호(처음엔 `0000`)를 꼭 바꿔요. 스티커 주기·지우기에 써요.

## 고칠 때 (개발용)
- 화면: `index.html`, `style.css`, `app.js`
- 동물 그림 원본은 `tools/source/`, 정리 스크립트는 `python3 tools/make_images.py` → `img/`에 투명 PNG가 만들어져요.
- 앱 파일을 고치면 `sw.js`의 `VERSION`을 올려요.
- 공휴일은 `app.js`의 `HOLIDAYS`에 해마다 다음 해를 더해요 (지금 2026~2027년).
